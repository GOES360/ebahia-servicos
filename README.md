# ÉBahia Serviços
Hub de utilidades do Portal ÉBahia.

## Escopo deste repositório
- Tempo na Bahia — integração inicial com Open-Meteo.
- Agenda Bahia — estrutura para eventos verificados.
- Empregos e Concursos — estrutura para vagas e fontes oficiais.
- Marés e Praias — aguardando fonte adequada.
- Mobilidade — aguardando integrações oficiais/confiáveis.
- Faixa rápida — preparada para indicadores econômicos e combustíveis.

## Projetos separados
- Esportes foi separado para GOES360/ebahia-esportes.
- Bahia Geek ficará em GOES360/ebahia-geek.

## Dados
Combustíveis devem usar os dados abertos/pesquisa semanal da ANP. Não preencher dados dinâmicos com valores inventados. Exibir fonte, período de referência e atualização.

Antes de monetização, revisar licenças/termos de cada provedor externo e substituir integrações quando necessário.
